## 🚀 Featured Project

### 🗣️ [SPEAKEASY — Bilingual Speech Practice Interface](https://github.com/Samirchauhan1/SPEAKEASY)

A React-based interface concept for guided speech-practice sessions in **Hindi and English**, designed around exercise selection, a listen/record/review journey, and progress screens.

**Built with:** React 19 · TypeScript · Vite · Tailwind CSS v4 · React Router

**What it explores**
- Structuring a multi-screen React application.
- Building navigation and language/exercise selection flows.
- Designing result and progress screens.
- Organizing UI components and application state.

**Honest project status:** Audio playback/recording is not fully wired up, scores are mock results, and progress uses sample data. The repository README documents the current limitations and development roadmap.
